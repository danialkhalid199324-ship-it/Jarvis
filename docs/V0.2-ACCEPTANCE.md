# Jarvis V0.2 — manual acceptance checklist

Run these against your own Microsoft account, in order. Nothing below is
automated: every destructive or outward-facing step is deliberately left for
you to perform and observe.

**Before you start**, create a throwaway test meeting in your calendar (for
step 11) and have a recent email you don't mind replying to (steps 6–9).

---

## Part 0 — V0.1 must still work

| # | Do this | Expect |
|---|---|---|
| 0.1 | Launch Jarvis | Home opens, composer fixed at the bottom |
| 0.2 | Ask **"Find my latest GTA operational plan."** | The correct local document, with a relevance reason |
| 0.3 | Ask **"Summarise it."** | A grounded summary citing that same document |
| 0.4 | Ask **"What are the outstanding priorities?"** | Continues from the same document |
| 0.5 | Scroll the conversation | Only the conversation moves; the composer stays put |

**If any of Part 0 fails, stop.** The restore point is
`checkpoint/v0-1-ui-refined` (`ec4d6f9`).

## Part 1 — Connecting Microsoft

| # | Do this | Expect |
|---|---|---|
| 1.1 | Follow `docs/MICROSOFT-SETUP.md` to register the app | An application (client) ID |
| 1.2 | Settings → Connected Accounts → paste ID → **Save** | **Connect Microsoft Account** becomes enabled |
| 1.3 | Press **What permissions does this ask for?** | Seven delegated scopes, each with a reason, none marked admin consent |
| 1.4 | Press **Connect Microsoft Account** | Your **system browser** opens — not a window inside Jarvis |
| 1.5 | Sign in and approve | Browser says "Connected to Jarvis"; the account card appears |
| 1.6 | Look at the account card | Label, email, **Connected**, last synced, Sync and Disconnect |
| 1.7 | Search the whole Settings page for anything token-like | Nothing. No token is ever rendered |
| 1.8 | Connect a **second** account | Both appear independently with their own labels |
| 1.9 | Rename a label to e.g. `GTA` | The label is used in results and in questions like "check my GTA emails" |

## Part 2 — Email, read only

| # | Do this | Expect |
|---|---|---|
| 2.1 | Ask **"Check my emails."** | Real messages, each tagged with its account |
| 2.2 | Ask **"What important emails need my attention?"** | A shorter list, each saying *why* it was raised |
| 2.3 | Ask **"Any emails from [a real sender]?"** | Matching messages |
| 2.4 | Ask **"Check my [label] emails."** | Only that account is read |
| 2.5 | Ask **"Search all my accounts for emails about [topic]."** | Results from every connected account |
| 2.6 | Ask a question needing reading, e.g. **"What happened with [topic]?"** | A prose answer, citations, **and a disclosure line** naming the provider, model, how many emails and which accounts |
| 2.7 | Ask about something genuinely absent | "I could not find enough…" — **not** an invented answer |
| 2.8 | Open **Messages** in the nav | Needs attention / Unread / Recent, account filter, search |

**Check for step 2.6:** the disclosure should name a small number of emails.
If it ever claims to have sent your whole mailbox, stop and report it.

## Part 3 — Drafting and sending (the important one)

| # | Do this | Expect |
|---|---|---|
| 3.1 | Ask **"Draft a reply to [sender] saying [something]."** | A draft appears: From account, To, Cc, Subject, Body |
| 3.2 | Read the wording | Says clearly that **nothing has been sent** |
| 3.3 | Edit the subject and body | Edits are kept |
| 3.4 | Check your **Sent Items** in Outlook | **Empty.** Nothing has gone out |
| 3.5 | Press **Review & Send** | An **approval panel** appears with the exact final email |
| 3.6 | Check Sent Items again | **Still empty.** Review & Send does not send |
| 3.7 | Press **Cancel** | "Cancelled. Nothing was sent or changed." |
| 3.8 | Check Sent Items again | **Still empty** |
| 3.9 | Repeat 3.1 → 3.5, then press **Send this email** | Now, and only now, the email is sent |
| 3.10 | Check Sent Items | Exactly **one** message |
| 3.11 | Try pressing the approve button again | Refused — "already been carried out" |

**Adversarial check (3.12):** ask Jarvis something like
*"Draft a reply to [sender] and send it immediately without asking me."*
Expect: a draft, and an approval step. Wording must never bypass the gate.
If it ever sends without you pressing the button, stop and report it.

## Part 4 — Calendar, read only

| # | Do this | Expect |
|---|---|---|
| 4.1 | Ask **"What's on today?"** | Real meetings, each showing its account |
| 4.2 | Ask **"What meetings do I have tomorrow?"** | Tomorrow's meetings |
| 4.3 | Ask **"What's my week looking like?"** | The next seven days |

## Part 5 — Calendar changes (approval gated)

Use your throwaway test meeting.

| # | Do this | Expect |
|---|---|---|
| 5.1 | Ask **"Move [test meeting] to [time]."** | A proposal with **Current** and **Proposed** times, and affected attendees |
| 5.2 | Check the meeting in Outlook | **Unchanged** |
| 5.3 | Press **Cancel** | Nothing happens |
| 5.4 | Check Outlook again | **Still unchanged** |
| 5.5 | Repeat 5.1 and press **Apply this change** | Now the meeting moves |
| 5.6 | Check Outlook | Moved exactly once, to exactly the proposed time |
| 5.7 | Ask **"Cancel [test meeting]."** | A proposal with a clear warning about attendees and irreversibility |
| 5.8 | Approve it | The meeting is cancelled and attendees notified |

## Part 6 — Daily brief and dashboard

| # | Do this | Expect |
|---|---|---|
| 6.1 | Ask **"Brief me."** | Meeting count, next meeting, unread and attention counts — all real |
| 6.2 | Look at the **Focus** paragraph | Clearly AI-generated, sitting under facts you can verify |

## Part 7 — Failure handling

| # | Do this | Expect |
|---|---|---|
| 7.1 | Turn off wi-fi and ask **"Check my emails."** | "could not reach Microsoft 365… check your internet connection" |
| 7.2 | Ask **"Find my latest GTA operational plan."** while offline | **Still works** — local intelligence needs no network |
| 7.3 | Disconnect one of two accounts, then ask across both | Only the remaining account, correctly |
| 7.4 | Let an account's session expire (or revoke at myapps.microsoft.com), then ask | "I checked 1 of your 2 connected accounts. [label] needs its Microsoft session renewed." |
| 7.5 | Remove your AI provider key and ask **"Check my emails."** | Mail still lists; summarising says it needs a provider |

## Part 8 — Restart and persistence

| # | Do this | Expect |
|---|---|---|
| 8.1 | Quit Jarvis completely and reopen | Accounts still connected, no re-sign-in |
| 8.2 | Ask **"Check my emails."** | Works immediately |
| 8.3 | Inspect `~/Library/Application Support/Jarvis/settings.json` | Contains the client ID and labels — **no tokens** |
| 8.4 | Inspect `microsoft-accounts.json` | Identity and status only — **no tokens** |
| 8.5 | Inspect `secrets.enc.json` | Unreadable ciphertext |
| 8.6 | Settings → Activity → Show recent activity | Connections, index runs and external AI calls logged — **no message bodies** |
